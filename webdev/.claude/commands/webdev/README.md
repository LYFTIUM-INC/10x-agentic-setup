## 📋 **Command Parameters Reference**

### **Common Parameters Across All Commands**
- `--parallel-agents`: Number of concurrent sub-agents (1-10)
- `--depth`: Analysis depth (quick, standard, comprehensive, enterprise)
- `--servers`: Target servers (production, staging, development, all)
- `--mode`: Operation mode (varies by command)
- `--monitoring`: Monitoring level (basic, standard, real-time, comprehensive)

### **Performance Parameters**
- `--optimization-level`: Optimization aggressiveness (conservative, balanced, aggressive)
- `--auto-implement`: Automatically apply safe optimizations (true, false)
- `--benchmark-against`: Comparison baseline (industry, competitors, previous)

### **Deployment Parameters**
- `--strategy`: Deployment strategy (blue_green, rolling, canary, atomic)
- `--rollback`: Rollback configuration (auto, manual, disabled, immediate)
- `--health-checks`: Health check frequency (continuous, periodic, disabled)
